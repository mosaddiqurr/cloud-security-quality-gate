# Cloud Security Quality Gate

Automated cloud security validation using Conftest,
Parliament, Gitleaks and GitHub Actions.

## Project Objectives

- Enforce custom Terraform security policies.
- Validate AWS IAM permissions.
- Detect secrets in files and Git history.
- Reject insecure changes through GitHub Actions.

## Tools

- Conftest 0.71.1
- Parliament 1.6.4
- Gitleaks 8.30.1
- GitHub Actions

## Status

Experimental validation completed.
GitHub Actions integration testing in progress.

## Safety

All infrastructure examples are fictional.
No AWS deployment or credentials are required.
